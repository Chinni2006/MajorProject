What would make these recommendations a better fit?
Credixa Studio · Resume text is encrypted for account storage. Model and search API keys stay in this browser session. Resume text is sent to your selected LLM provider when you request analysis, editing, or job matching.

Connect your tools

API keys are optional. Without keys, local resume analysis and the public remote-job feed are used. Keys you add stay in this tab only.

The local backend proxies requests to the selected provider; it does not store keys or resume text. API usage may be billed by your provider. On-chain writes require a wallet and network gas.
